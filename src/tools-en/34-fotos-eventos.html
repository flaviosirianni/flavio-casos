Private event photos and videos

Event web app in advanced development

Browser uploads, a private gallery and moderation and export tools for the organizer.

Technical implementation

I implemented a React interface and Cloudflare Workers services with D1 and R2. The code includes guest access, multipart uploads with local persistence, media processing, moderation and batch exports.

What it solves

After an event, photos are often scattered. An event gallery gathers guest contributions and lets the organizer manage files in one place.

Flow and scope

Guests open the event link and select files. An interrupted upload retains confirmed progress and can resume after selecting the file again. The organizer reviews media and requests exports. The platform remains in advanced development.

  • Guest access without creating an individual account.
  • File validation and processing states.
  • Moderation and batch export of originals.
