Workout logging and progress

Mobile PWA in invitation-only beta

Beta PWA with set logging, private history and synchronization after working offline.

Technical implementation

I built a React and TypeScript PWA with domain rules independent of the interface. Dexie stores account-specific records in IndexedDB; Supabase synchronizes revisions and stores private photos.

What it solves

Logging between sets needs to be quick and work without reception. The app records weight and repetitions, retrieves the previous session and shows progress by exercise.

Flow and scope

The beta runs in the phone browser with invitation-only access. It saves locally first, then synchronizes a change queue. Concurrent edits create a reviewable conflict instead of silently overwriting data.

  • Sessions, routines and a personal exercise catalogue.
  • Account-specific local storage and private photos.
  • History and comparisons per exercise.
