CSV generator with local UI and CLI · Implemented

Start from a sample CSV, adjust column rules and generate repeatable data without real records.

Technical implementation

A shared Node.js engine preserves headers, infers types and streams generated rows. It supports seeds, entity pools, grain-based modes and formulas through a restricted parser.

Problem solved

Enables demos and tests with coherent structure and a retained configuration for reproducing results.

Flow and scope

The Express UI inspects one file, offers a dry run and downloads CSV plus configuration. The CLI supports several tables and shared pools to maintain relationships.

  • Headers and column order preserved.
  • Configurable unique keys, null values, date ranges and distributions.
  • Validation summary and seed-based reproducibility.
