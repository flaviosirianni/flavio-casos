Projects, costs and effort intranet

Private project management intranet

Provider costs, development work logs and estimates brought together in a private intranet.

Technical implementation

I built project, cost reconciliation and work-log modules in Next.js and Supabase. Integrations query the OpenAI administration API and Google Cloud billing exports in BigQuery.

What it solves

Estimating effort and understanding project cost requires connecting providers, development activity and projects. The intranet brings those references together without relying on separate spreadsheets.

Flow and scope

Costs are linked to projects, work entries are ingested and historical references are summarized to estimate effort. Calculations distinguish observed values from estimates based on small samples.

  • Reconciliation and deduplication of imported costs.
  • Work log with project, category and duration.
  • Estimation using references and complexity factors.
