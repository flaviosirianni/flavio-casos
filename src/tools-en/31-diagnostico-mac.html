Guided computer diagnostics

Terminal tool for macOS diagnostics

Local read-only checks that distinguish measurements, alerts and incomplete data.

Technical implementation

I implemented a Bash check that integrates a diagnostic methodology and scales the swap threshold to RAM. Python tests use fixtures to verify signals and errors without exposing machine information.

What it solves

A slow computer can have several causes. The check gathers signals and avoids treating a failed measurement as a healthy result.

Flow and scope

The flow measures memory, disk, backups and system reports. It retains read limitations and requires interpretation before concluding a cause. The check does not delete files or change settings.

  • Thresholds related to the machine’s RAM.
  • Incomplete data explicitly identified.
  • Private local evidence; demo uses fictional values.
