Internal operations tool portal

Web portal for accessing internal applications

An internal catalogue with descriptions, categories and status for opening a suite’s applications.

Technical implementation

I built a portal served by Google Apps Script. Central configuration defines the applications, and the bootstrap returns their names, descriptions, categories, status and destinations to the browser.

What it solves

Scattered links make it difficult to know which application to use. The portal offers a common entry point and explains each tool’s purpose.

Flow and scope

The operator reviews the catalogue and opens an available application. Planned tools without an enabled destination appear as upcoming; the portal does not make them operational features.

  • Access to commissions and payroll hour review.
  • Visible status for each application.
  • Catalogue maintained through shared configuration.
