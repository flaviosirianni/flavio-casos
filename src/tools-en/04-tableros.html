Operational services · multiple implementations

Management dashboards with role-based access

BI over a shared analytics warehouse

Each profile accesses authorized topics and filters metrics in the browser. Implementations cover attendance, service issues, billing, collections or stock depending on the context.

Technical implementation

I configured Apache Superset on Cloud Run, with PostgreSQL metadata and BigQuery read access. Dashboards, datasets and charts are versioned in YAML; Google login synchronizes the roles defined for each user.

What it solves

It avoids distributing reports without access controls or rebuilding metrics in every spreadsheet. Teams query metrics over shared transformations with topic-based permissions.

Flow and scope

Authorized access determines which dashboards appear; filters adjust the period, site and other dimensions. The demo represents an issues dashboard with fictional figures, not a connected session.

  • Google OAuth with an allowlist and role synchronization at login.
  • Reproducible asset imports using stable identifiers.
  • Business data in BigQuery; Superset metadata in PostgreSQL.
