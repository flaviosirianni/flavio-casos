Digital attendance and daily updates

Operational web app connected to Sheets

The supervisor enters the day in a web app, reviews differences and confirms when everything is complete. History retains posted records.

Technical implementation

I extended Google Sheets operations with an HTML/JavaScript interface and Apps Script APIs. Validation, locks, absence rules and confirmation run on the server; outputs integrate with the analytical layer.

What it solves

It organizes attendance, absences and actual times without requiring direct cell editing. It distinguishes drafts, posted rows and confirmed days.

Flow and scope

Users choose a date and active staff, enter updates and post records. Confirmation checks pending items before closing; historical changes have a dedicated flow.

  • Individual or batch posting with data validation.
  • Rules for active staff, absences and departures.
  • Concurrency locks and controlled historical editing.
