Personal product · shared infrastructure

Credits and payments for AI services

Wallet and payment backend service

Shared wallet for checking balances, recording usage and crediting top-ups with duplicate checks.

Technical implementation

I implemented an HTTP service and SQLite database containing wallets, transactions, usage events and processed payments. The Mercado Pago integration verifies payments and uses idempotency identifiers.

What it solves

Several assistants need to share balances and trace usage. A central service keeps each bot from implementing separate billing logic.

Flow and scope

The user checks their balance, spends credits and tops up through the payment provider. Retries are recognized to avoid repeating a transaction, and the history makes events reviewable.

  • Credit and debit transactions per user.
  • Payment confirmation before crediting.
  • Operation identifiers to detect retries.
