Automated appointment search and booking

Web app with a search and booking engine

Specialty, location and time preferences connected to an engine that searches for and books matching appointments.

Technical implementation

I built a Next.js web app on Supabase and a Python engine with Playwright. The engine matches portal availability against configured locations and time windows, records results and sends email notifications.

What it solves

Repeatedly checking an appointment portal takes time. A persistent search captures when and where each person can attend.

Flow and scope

The user configures a search, the engine reviews options and attempts to book a matching slot. History distinguishes searches, bookings and situations requiring manual review. The integration depends on the specific implemented portal.

  • Filters by location and weekday.
  • Time windows and activity history.
  • Notifications for bookings and failures requiring attention.
