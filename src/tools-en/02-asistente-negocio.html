Commercial operations · internal queries

Business queries through a chat assistant

Assistant connected to an analytics warehouse

An everyday question becomes a query against prepared data. The answer states the period and can continue with details or an export.

Technical implementation

I built the Telegram → planning → SQL generation and validation → BigQuery → response flow. It includes conversational context in Firestore, query validation and output file generation.

What it solves

It makes sales, receipts, purchases and debt accessible to users who need answers without writing SQL. The collections schedule uses specific rules and tables alongside open-ended queries.

Flow and scope

The assistant interprets the question, consults the catalog and validates SQL before reading BigQuery. It can preserve context for follow-ups and export results; it does not record payments or alter the ERP.

  • Validation of SELECT/WITH queries, permitted datasets and estimated cost through a dry run.
  • Period comparisons using comparable data coverage.
  • Collections scheduling and XLSX/PDF exports are implemented.
