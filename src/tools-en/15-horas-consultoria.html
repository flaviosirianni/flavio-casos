Technical implementation

Apps Script validates identity, dates and active projects before appending entries. It rebuilds weekly and project summaries and prepares Slack upload notifications.

Problem solved

Organizes individual and bulk entries in a shared base so coordinators can review work and project consumption.

Flow and scope

The web app accepts individual rows and tabular text. Clients with several active projects require an explicit selection; the spreadsheet retains entries and derived summaries.
