Sitios institucionales y portal de empleos

Sitios web con portal de oportunidades y API

Sitios bilingües con búsqueda de vacantes, envío de CV y formularios conectados al equipo.

Implementación técnica

Implementé interfaces Astro con componentes React y APIs Hono sobre Cloudflare Workers. Los adaptadores separan vacantes y postulaciones en Google Sheets, CV en R2 y notificaciones con Resend.

Qué resuelve

Empresas y candidatos necesitan recorridos distintos en el mismo sitio. Los formularios estructurados permiten recibir consultas y postulaciones con los datos necesarios para continuar.

Recorrido y alcance

El candidato filtra vacantes, consulta el detalle y adjunta su CV. La API valida el envío, conserva el archivo y registra la postulación. La interfaz ofrece contenido en español e inglés.

  • Listado de vacantes con filtros y paginación.
  • Validación de formularios y archivos adjuntos.
  • Registro de postulaciones y aviso al equipo.
