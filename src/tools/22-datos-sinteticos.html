Equipos de datos y desarrollo

Generación de datos para pruebas y demostraciones

Aplicación web local y herramienta por línea de comandos, con un motor compartido

Subís un CSV de ejemplo, ajustás cómo se genera cada columna y obtenés miles o millones de filas creíbles, con las mismas columnas y relaciones consistentes entre tablas. Ideal para demos, pruebas de carga o validar reportes sin datos reales.

Implementación técnica

Desarrollé un motor de generación en Node.js con interfaz de línea de comandos y una UI web con Express. Ambas entradas comparten reglas de esquema y generación de CSV para pruebas y demos reproducibles.

Qué hace

Produce archivos de datos sintéticos a partir de una estructura de ejemplo. Permite elegir cantidades, fechas, distribuciones y reglas por columna, y mantener referencias compartidas entre varias tablas. La configuración se guarda para repetir una generación. Puede utilizarse desde una interfaz local o por comandos, para preparar demos, validar reportes o probar una aplicación con distintos volúmenes.

Permite preparar escenarios de distinta escala, generar valores repetibles y probar reglas de negocio sobre datos controlados. La interfaz ayuda a revisar columnas y tipos antes de descargar el resultado; los comandos permiten repetir la misma tarea dentro de un flujo de trabajo.

Genera datos nuevos a partir de una estructura; no es una herramienta de anonimización de datos reales.
