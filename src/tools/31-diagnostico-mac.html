Diagnóstico guiado de computadoras

Herramienta de terminal para diagnóstico de macOS

Chequeo local de solo lectura que separa mediciones, alertas y datos incompletos.

Implementación técnica

Implementé un chequeo Bash que integra una metodología de diagnóstico y escala el umbral de swap según la RAM. Los tests Python usan fixtures para comprobar señales y errores sin exponer información del equipo.

Qué resuelve

Una computadora lenta puede tener distintas causas. El chequeo reúne señales y evita confundir una medición fallida con un estado saludable.

Recorrido y alcance

El recorrido mide memoria, disco, respaldos y reportes del sistema. Conserva las limitaciones de lectura y requiere interpretación antes de concluir una causa. El chequeo no borra archivos ni modifica configuración.

  • Umbrales relacionados con la RAM del equipo.
  • Datos incompletos señalados explícitamente.
  • Evidencia local privada; demo con valores ficticios.
