Créditos y pagos para servicios con IA

Servicio backend de billetera y pagos

Billetera compartida para consultar saldo, registrar consumos y acreditar recargas con control de duplicados.

Implementación técnica

Implementé un servicio HTTP y una base SQLite con billeteras, movimientos, eventos de uso y pagos procesados. La integración con Mercado Pago verifica pagos y usa identificadores de idempotencia.

Qué resuelve

Varios asistentes necesitan compartir saldo y dejar trazabilidad del consumo. Un servicio central evita que cada bot mantenga su propia lógica de cobro.

Recorrido y alcance

El usuario consulta saldo, consume créditos y recarga mediante el proveedor de pagos. Los reintentos se reconocen para evitar repetir el movimiento; el historial permite revisar qué ocurrió.

  • Movimientos de crédito y débito por usuario.
  • Confirmación del pago antes de acreditar.
  • Identificadores de operación para detectar reintentos.
