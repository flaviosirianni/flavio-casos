Registro y seguimiento de entrenamiento

Aplicación web progresiva para registrar sesiones y revisar el progreso

Aplicación en beta para registrar ejercicios entre series, consultar la sesión anterior y seguir el progreso. Funciona como web y PWA, con guardado offline y sincronización al recuperar conexión. Las pantallas siguientes son recreaciones ilustrativas del flujo.

Implementación técnica

Desarrollé una PWA con React, TypeScript y Vite. Dexie/IndexedDB conserva registros offline; Supabase proporciona autenticación y PostgreSQL con políticas por usuario. Implementé sincronización y validaciones con Vitest y Playwright. La aplicación está en beta.

Qué hace

Aplicación web en beta para registrar repeticiones, peso y cardio, organizar rutinas y revisar progreso por ejercicio. El primer acceso requiere conexión; después permite guardar registros offline y sincronizarlos mientras la aplicación está abierta.

La beta dispone de cuentas por invitación, catálogo de ejercicios y fotos privadas. Las funciones de IA y una app nativa de iPhone corresponden a etapas posteriores.
