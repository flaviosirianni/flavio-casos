Actualización de tareas de servicios de campo

Integración de datos de tareas con operación y consulta en Google Sheets

Las tareas de campo, sus responsables y estados se copian solos a una planilla que el equipo ya sabe usar. Cuando una tarea cambia, se actualiza la misma fila; no hay que exportar nada para cada revisión.

Implementación técnica

Desarrollé una integración REST con FieldRoutes en Apps Script. Implementé extracción y transformación de tareas hacia Sheets, con funciones de soporte verificables y salidas para análisis operativo.

Qué hace

Recupera tareas desde una plataforma de gestión de campo y mantiene una planilla con responsables, estados y fechas. Incorpora el histórico y actualiza tareas existentes cuando cambian sus datos. Permite consultar y analizar el trabajo desde una fuente común, con seguimiento de las cargas y de los registros que requieren revisión.

Los responsables pueden analizar tareas y responsables desde una planilla habitual sin realizar una exportación nueva para cada revisión. Las actualizaciones conservan la identidad de cada tarea para reflejar sus cambios en el mismo registro.
