Lectura de fichadores y conciliación de asistencia

Integración de marcaciones y control cruzado

Las marcaciones dejan de ser una consulta aislada del reloj. Se transforman en registros diarios que pueden compararse con el parte y el padrón.

Implementación técnica

Implementé una ingesta Python desde la API de fichadores hacia particiones diarias de BigQuery. Las transformaciones SQL separan turnos y cruzan las marcaciones con los partes; hay auditorías de dispositivos y latencia.

Qué resuelve

Permite detectar días con parte y sin fichada, fichadas sin parte y otras diferencias que requieren revisión. Aporta una base común para distinguir el registro del dispositivo de la carga administrativa.

Flujo y alcance

La API se consulta por fecha y cada partición se reemplaza para evitar duplicar la carga. Los datos se normalizan y se publican vistas de conciliación, con salidas específicas hacia resúmenes de Sheets.

  • Reintentos de lectura y normalización de dispositivos.
  • Separación de turnos y tratamiento de marcaciones repetidas.
  • Clasificación de coincidencias y diferencias; la revisión sigue siendo humana.
