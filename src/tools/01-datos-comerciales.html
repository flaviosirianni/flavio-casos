Centralización de información comercial y contable

Integración automática de datos y base analítica centralizada

El sistema contable sigue siendo la fuente; nosotros lo copiamos cada hora a una base analítica ordenada. Ventas, cobros, compras y saldos quedan listos para consultar, armar tableros o responder por chat, sin exportar planillas módulo por módulo.

Implementación técnica

Desarrollé un pipeline en Python para extraer datos de una API REST, cargar históricos y sincronizar cambios en BigQuery. Separé datos crudos, staging y vistas SQL, con ejecución programada en Cloud Run, reintentos y snapshots de recuperación.

Qué hace

Reúne automáticamente ventas, compras, cobranzas, pagos, productos, clientes y proveedores en una base común para consultar y analizar. Mantiene un histórico, incorpora cambios posteriores y prepara información consistente para reportes y tableros. Permite seguir la evolución del negocio y consultar cuentas corrientes sin reunir exportaciones manuales de cada módulo. Incluye controles de actualización, respaldos y avisos ante fallas.

La administración puede revisar lo vendido, lo cobrado, las compras y los saldos desde una fuente organizada. La actualización contempla cambios sobre registros anteriores y permite reconstruir períodos históricos cuando es necesario, con seguimiento de las fuentes que todavía no se actualizaron.

Detalles que importan

  • Capas separadas: datos crudos, preparados y vistas de negocio (cuenta corriente, ventas mensuales, agenda de cobro).
  • Ventana de revisión para captar cambios tardíos y conciliación de comprobantes anulados.
  • Reintentos, particiones por fecha y cortes de seguridad para convivir con los límites de la API del ERP.
  • Snapshots antes de cada promoción, para volver atrás si algo sale mal.

Es la base de otras soluciones del mismo cliente: el asistente por Telegram, la agenda de cobranzas y los tableros de gestión leen de acá.
