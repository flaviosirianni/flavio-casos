Asistente para consultar el negocio por chat

Asistente conectado a una base analítica

Una pregunta cotidiana se convierte en una consulta sobre datos preparados. La respuesta explicita el período y puede continuar con un detalle o una exportación.

Implementación técnica

Construí el flujo Telegram → planificación → generación y validación SQL → BigQuery → respuesta. Incluye contexto conversacional en Firestore, validación de consultas y generación de archivos de salida.

Qué resuelve

Acerca ventas, cobros, compras y deudas a usuarios que necesitan respuestas sin escribir SQL. La agenda de cobranza usa reglas y tablas específicas, además de las consultas abiertas.

Flujo y alcance

El asistente interpreta la pregunta, consulta el catálogo y valida el SQL antes de leer BigQuery. Puede conservar contexto para seguimientos y exportar resultados; no registra pagos ni altera el ERP.

  • Validación de SELECT/WITH, datasets permitidos y costo estimado mediante dry-run.
  • Comparaciones entre períodos con cobertura comparable.
  • Agenda de cobranza y exportaciones XLSX/PDF implementadas.
