# Portfolio personal de Flavio Sirianni

Solicitud: duplicar el catálogo visual existente como proyecto personal independiente, sin identidad corporativa, con stack por caso y orientación a programación.

Se conserva el catálogo más reciente de 37 casos, las capturas recreadas y reales del demo público, las categorías, los estados de desarrollo y la navegación por hash. La portada presenta a Flavio Sirianni como desarrollador de aplicaciones, datos y automatizaciones, sin inventar títulos, antigüedad ni métricas. La interfaz adopta una identidad tipográfica con monograma FS y acento verde. Cada caso muestra el stack completo y una explicación concreta de implementación. Se agrega filtro exacto por tecnología y una página de CV técnico imprimible, sin datos de contacto inferidos.

El sitio es estático, sin dependencias de producción ni secretos. El build genera HTML válido y copia imágenes a rutas relativas, compatible con GitHub Pages en un subdirectorio y con apertura local. El repositorio nuevo comienza con historial limpio de la versión personal. El proyecto de origen no se modifica.

Validación: build repetible; catálogo completo; ausencia de marca corporativa; recursos y enlaces internos resueltos; filtros combinados, búsqueda sin acentos, vacíos, recuperación, historial, ancla inexistente, todos los casos, CV, tema oscuro y móvil en Playwright. Publicación desde la rama de entrega en GitHub Pages y comprobación HTTP posterior.
